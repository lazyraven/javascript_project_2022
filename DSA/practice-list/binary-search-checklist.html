JavaScript Template You Should Master

Before starting the harder problems, get comfortable with this classic binary search template. 

function binarySearch(arr, target) {
    let left = 0;
    let right = arr.length - 1;

    while (left <= right) {
        const mid = left + Math.floor((right - left) / 2);

        if (arr[mid] === target) {
            return mid;
        }

        if (arr[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return -1;
}

Boundary Template

function lowerBound(arr, target) {
    let left = 0;
    let right = arr.length;

    while (left < right) {
        const mid = left + Math.floor((right - left) / 2);

        if (arr[mid] < target) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }

    return left;
}

The 5 Key Binary Search Patterns

Don't just memorize 50 solutions. Learn to identify these 5 Binary Search patterns:

1. Exact Search "Does target exist?"
2. Boundary Search "First / last position?"
3. Rotated / Peak Search "Find the peak element?"
4. Binary search on answer → "Is answer X possible?"
5. Partition Search "Can I divide two/multiple sorted structures optimally?"
